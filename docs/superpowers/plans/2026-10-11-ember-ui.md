### Task 3: `lib/timeline-view.ts` — gerçek veriden timeline

**Files:**
- Create: `apps/web/src/lib/timeline-view.ts`
- Test: `apps/web/test/timeline-view.test.ts`

**Interfaces:**
- Consumes: `RunView`, `StepView`, `StepKey`, `STEP_DEFAULT_S`, `formatClock` (`@videogen/shared/browser`); `STEP_EN` (`lib/i18n.ts`).
- Produces:
  - `type LaneId = 'V' | 'A' | 'QC'`; `LANE_OF: Record<StepKey, LaneId>` — V: research, storyboard, build, draft_render, final_render, compose, finalize; A: voice, music, remix; QC: draft_review, qc, review.
  - `type BlockTone = 'done' | 'live' | 'pending' | 'waiting' | 'failed' | 'stopped' | 'skipped'`.
  - `interface TimelineBlock { id: string /* StepView.id */; key: StepKey; label: string; lane: LaneId; startPct: number; widthPct: number; tone: BlockTone; started: boolean; title: string }` — yüzdeler 0..100, `skipped` bloğun `widthPct` 0 (bileşen 4px işaret çizer); `title` = İngilizce ad + durum + süre + varsa `round N`/`fix N`.
  - `interface TimelineView { totalS: number; playheadPct: number; ticks: { pct: number; label: string }[] /* 5 nokta: 0, 25, 50, 75, 100 */; lanes: { id: LaneId; blocks: TimelineBlock[] }[] /* her zaman V, A, QC sırası; boş şerit de döner */; now: { kind: 'live' | 'done' | 'stopped' | 'failed' | 'queued'; clock: string /* h:mm:ss ya da m:ss */; note: string | null } }`.
  - `timelineView(run: RunView, nowMs: number): TimelineView`.
- Kurallar (spec E11 + düzeltme): sıra `ordinal`, sonra dizi sırası; süre: `done` → `endedAt − startedAt`; `running`/`waiting_*` → `max(now − startedAt, STEP_DEFAULT_S[key])`; `pending`/`queued` → `STEP_DEFAULT_S`; `failed`/`cancelled` başlamış → `(endedAt ?? run.endedAt ?? now) − startedAt`; `cancelled` başlamamış → `STEP_DEFAULT_S`, ton `stopped`, `started:false`; `skipped` → 0. Bütün süreler `max(0, …)`. Asgari genişlik: `skipped` dışındaki her blok toplamın %4'ünden küçükse %4'e çıkarılır, sonra bütün genişlikler toplam 100 olacak biçimde yeniden ölçeklenir; `startPct` birikimli. Playhead: bitmiş/başarısız/başlamış-iptal blokların toplam gerçek süresi + koşanın geçen süresi, aynı ölçekle yüzdeye; koşu bitmişse 100. Ton: done → `done`; running → `live`; `waiting_*` → `waiting`; failed → `failed`; cancelled → `stopped`; pending/queued → `pending`; skipped → `skipped`. `now.kind` tablosu: run `running` → live; `queued` → queued; `done` → done; `cancelled` → stopped; `failed` → failed; `needs_human` → done (Studio'daki amber vurgu VideoHeader ve NeedsYou'dan gelir, timeline yalnız zamanı gösterir). `clock`: live/queued → `now − run.startedAt` (yoksa 0); diğerleri → `(run.endedAt ?? now) − run.startedAt`. `note`: koşan adımın `note`'u, yoksa son başlamış adımın `note`'u ya da `error`'u. `ticks` etiketi `formatClock(totalS * pct/100)`.
- [ ] Testleri yaz (sabit `nowMs`, elle kurulmuş RunView fikstürleri): "done step width is its real duration"; "running step uses the default until it outlives it"; "pending steps use STEP_DEFAULT_S"; "every STEP_KEYS entry belongs to exactly one lane"; "lanes always come back in V, A, QC order"; "tiny steps get at least 4 percent and widths still sum to 100"; "skipped step has zero width and is not stretched"; "cancelled before starting is stopped, not started, default width"; "started then cancelled keeps its real width and started:true"; "playhead sits at done plus elapsed of the running step"; "finished run puts the playhead at 100"; "repeated key yields two blocks with distinct ids in order"; "clock skew clamps to zero" (now < startedAt → genişlik ≥ 0, playhead ≥ 0, clock `0:00`); "all skipped run has totalS 0 and finite positions" (NaN yok, ticks `0:00`); "now is live with the running step note"; "now clock uses h:mm:ss past an hour"; "needs_human run reports the last step note".
- [ ] Kırmızı gör; uygula; yeşil.
- [ ] `now.kind` tablosunu `timeline-view.ts` dosya başı yorumuna yaz.
