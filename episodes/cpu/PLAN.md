# CPU — Farklılaşma planı (bölüm 3)

Soru: "Kalem ve klavyeyi izlemiş biri bunu açınca ilk 2 sn'de 'aa bu farklı' der mi?" → Evet: ışık taraması,
ekranda 3 şıklı tahmin oyunu ve "cevap sonda" vaadi; tanıdık lacivert stüdyo içinde yeni bir oyun formatı.

| Eksen | Kalem / Klavye | CPU (bu bölüm) |
|---|---|---|
| Kanca | Soru metni ("İÇİNDE NE VAR?") | **Tahmin oyunu**: "TAHMİN ET: Bu minik çipte kaç ANAHTAR var?" A) 20 bin B) 20 milyon C) 20 milyar + lazer tarama çizgisi + "cevap sonda 👀" |
| İçeri giriş | Patlatılmış görünüm | **Lazerle kesip soyma** (kapak kesilip uçar, termal lehim eriyip kaybolur, çip ters çevrilir) + **mikro ölçekte küçülerek dalış** (çip → çekirdek → bakır yollar → transistör) |
| Kamera | Yavaş tur, dalış | **Dikey "asansör" inişi + speed ramp + beat'e senkron zoom-punch kesmeler**, ölçek HUD'u (×1 → ×1.000.000) |
| Mekanizma | Basış → temas → kıvılcım | **Enerji akışı**: kapıya voltaj → kanal parlar → elektron akışı = 1, voltaj yok = 0; ikili okuma şeridi + "5 GHz = saniyede 5 milyar tık" |
| Tema | Lacivert stüdyo + ızgara, sarı | (revize) Aynı aile: lacivert stüdyo, **nokta ızgara**, açık mavi çerçeve, sarı numara rozetli etiketler, dirsekli çizgi; turuncu kaynak/akaç, altın-mavi çip deseni |
| Ritim | 120 BPM pop-sentez | (revize ×2) **Klavye müziği** (120 BPM Am–F–C–G pad + sekizlik bas), bölümler CPU kurgusuna göre: drop lazerde, kırılma dalışta, yarım tempo mekanizmada |
| Retention | "ekran: HEY" sayacı | **Cevap sonda** vaadi + derinlik/ölçek göstergesi + ikili sayaç |
| Final | Tuş yağmuru + "Sıradaki nesne?" | **Hızlı geri zoom (ters powers-of-ten)**, cevap açılır (C ✅ ≈20 milyar), kapak geri uçup oturur; CTA "Tahminin tuttu mu? Yaz 👇"; son kare = ilk kare |

Seri kimliği korunur: 1080×1920/30 fps, ~30 sn, güvenli alan, çapa takipli etiketler, iki seviye içeri
(paket katmanları + transistör mekanizması), doğrulanmış vay bilgisi, yorum CTA, döngü, Türkçe.
Kanal reklamı: kapakta (IHS) kazınmış "WHAT'S INSIDE" + logo + @whatsinit.lab. Gerçek marka yok.
